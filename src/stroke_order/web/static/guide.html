筆順練習紙產生器——給老師的一頁說明

免費、免登入、免安裝。生字進去，可以印的紙出來。 黑白影印機印出來一樣清楚。

1. 印一份生字字帖（約一分鐘）

  1. 打開首頁，在「字帖」模式的字串欄輸入這課的生字（例：春天日月）。
  2. 想省打字：用「分級選字」輸入字頻名次一鍵帶入 （名次是常用程度的排序，不代表年級難度）。
  3. 可勾「注音欄」（注音也能描紅）與「頁尾生字資訊」 （部首、筆畫、教育部辭典的字義原文與造詞）。
  4. 按「下載 A4 PDF」→ 直接印。
開啟字帖產生器

2. 印筆順分解圖（取代到別的網站抓圖）

每個字一條「第 1 筆、第 1–2 筆、…」的分解圖：已寫的筆畫淡灰、 正在寫的濃黑、右上角標第幾筆。字帖模式輸入生字後，按 「筆順分解圖 → 下載 A4 PDF」即可，一次可出整課的字。筆順採 教育部標準楷書資料，不必再去外站截圖。

3. 課堂上教一個字（投影／平板）

教學頁輸入一個字，就有逐筆順動畫、注音發音、 部件拆解，以及教育部辭典的字義原文；頁面附教育百科的 QR Code——印在教學單上，學生回家掃碼就能自學。

開啟教學頁

4. 進階：把手寫變成字型、做雷雕字模

在手寫練習裡寫過的字，可以一鍵打包成能安裝到電腦的手寫字型 （字型裡每個字都是本人手寫，著作權歸書寫者）。另有噴漆字模、 雷雕鏤空字、立體字卡片等勞作／maker 功能，適合藝文課延伸。

找不到某個字？字帖與動畫涵蓋常用字；查無的字系統會誠實顯示 「查無此字」而不是給錯的資料——遇到需要的缺字，歡迎回報。
