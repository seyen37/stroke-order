# 打包經文文本來源與授權註記

`builtin/` 內 53 部文本隨套件散布（Phase 5bp 打包 fallback），
供部署環境（如 Render）與新安裝開箱即用。使用者放在
`~/.stroke-order/sutras/builtin/` 的同名檔**永遠優先**於打包版。

## 授權分類

- **古籍原文（公有領域）**：佛經（大正藏底本）、道藏、四書、蒙學、
  唐宋詩文等——原文著作權已消滅。標點與分段為本專案自行整理或
  通行慣用式樣。
- **聖經章節**：和合本（1919 年出版，公有領域）。
- **信經／禱文**：使徒信經、尼西亞信經、主禱文、聖母經等教會通用
  中文文本，屬長期共同流傳之儀文。
- **科普資料（事實彙編）**：元素週期表譯名（國家教育研究院）、
  九九乘法口訣、二十四節氣、康熙部首、倉頡字根、大寫數字、
  生肖時辰、太陽系天體——事實與短語彙編，無著作權適格性疑慮。

## 未打包（保守排除）

- `macarthur_prayer`（麥克阿瑟為子祈禱文）：原文 1942 年著作＋
  通行中譯本之著作權狀態未確認，不隨 repo 散布。本機使用者仍可
  自行將文本放入 `~/.stroke-order/sutras/builtin/` 使用，
  preset metadata 保留。

## 維護

新增 builtin preset 時：文本放本目錄 `builtin/<key>.txt`（UTF-8、
NFC、LF），並在本檔補充來源；有著作權疑慮者比照 macarthur 模式
只留 metadata 不打包。
