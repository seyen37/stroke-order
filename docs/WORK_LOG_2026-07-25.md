## 5gc：收工腳本訊息檔消費制（`edfebba` 同批）

跨日 STALE 三連發的根因是**啟發式守門**（檔名日期＝今天才放行）誤判合法
情境（訊息前一晚備好、隔天早上跑 bat）。根治改**狀態機消費制**：

- 訊息檔 pending → used：`git commit -F` **成功後**把用掉的檔案（連同更舊
  的 pending——累積式訊息已涵蓋其內容）移入 `docs\_commit_msg\used\`；
  commit 失敗則保留 pending 不消費。
- 日期不符降為 WARNING＋`choice` 確認（跨夜按 Y 續行；真沒準備按 N 中止）。
- **首航實測**：第一次執行即自動歸檔 191 個歷史訊息檔（正是「7/19 訊息落
  7/22 commit」類事故的火藥庫），此後 pending 資料夾只剩未入帳的訊息。

## 5gf：模式識別色具名 token 化（v0.14.280，`f56049f`）

主頁 inline 殘餘 hex 的大宗是各模式欄位框的「家族色」（刻意的識別設計，
不是債）——該做的是**具名化**而非消滅。收斂 16 個 token：`--chip-bg`
（一口氣收 31 處）/`--chip-bg-alt`/`--warn-bg`（與 `--gl-warn-bg` 同值）＋
六族 `--callout-{make,teal,warm,green,lavender,decor}-{bg,accent}`＋
`--decor-ink`；同族雜色順手歸一三處（#b09a66→make、#8cc→teal、#d97→
warm）。DESIGN.md §2 新增識別色附表（同步鎖自動接手驗證）；散寫回流鎖
擴到 21 色（3 碼 hex 用「後不接 hex 字元」邊界防誤中、token 定義行豁免）。

**驗收哲學**：token 化的驗收是「證明沒變」——E2E 取代表性元素的
computed style 逐一比對＝原色值（token 解析成功、非透明回退）。
