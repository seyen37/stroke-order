## 二、5dj-1：iCSO 五大基本符號＋延伸引擎地基＋三排工具列（0.14.181）

使用者提供禪繞畫理念知識：任何圖樣都拆解成五個最簡筆劃「iCSO」

QODA 三案 sign-off：三排工具列／延伸技法每區段獨立勾選／本輪先

分層架構（正交、沿用既有 spec 協定）：
- **基本層**：`tangle.mjs` 加 5 個 iCSO builder，registry 加
  `category`（basic／classic），既有 8 圖樣＝classic；
  `listTangles({category})` 過濾。全部共用 `orientSpecs` 朝向。
- **延伸層（新 `enhancers.mjs` 純模組）**：把已生成 spec 後處理。
  第一批三個最泛用——Aura 光環線（外擴平行副本）／Weighting 加厚

  準、與紙磚旋轉/朝向解耦）。
- **資料模型**：region 加 `enhancers` 欄位（per-region 獨立）；
  `setRegionEnhancer` 沿 5di 套用模型。UI 三排（basic 縮圖／enhancer
  toggle／classic `<details>` 收合）。

驗證：node +21（含修 5df-1 舊斷言 registry 8→13＝§8.3 應驗）→ 208；

## 九、雲端 Cowork 工作階段（本弧全程）

本弧是專案首度全程在**雲端 Cowork 工作階段**（而非本機模式）
進行。差異與陷阱：
- **雲端沙箱有外網**：`git ls-remote` / `git clone` 可通 →
  fetch-first 可由助理自跑、不必請使用者開 PowerShell。權威版本
  仍在 Windows 側，改權威檔＝沙箱改好 → SendUserFile → device
  bridge `device_commit_files` 寫回。
- **踩到的陷阱**（詳 §15.6）：①開工 `git reset --hard origin/main`
  會清掉磁碟上未 push 的前輪工作（5dj-4 在 clone 被 reset 掉、
  幸有 `/root/out` 副本可還原）②uploads 二次 stage 同路徑讀到舊
  md5（快取殘影，以 stage 回傳 bytes 或新檔名對照）③`device_bash`
  跑 `git status` 留下刪不掉的 `.git/index.lock` ④GitHub release
  字型 403（資料中心出站），用系統 Noto Serif CJK TC 抽 face 代打
  ⑤Playwright 收合 `<details>` 內控件要先點 summary 展開、screenshot
  clip 在長頁會 outside image（改 locator element screenshot）。

**5dm（0.14.189、本輪）**：使用者給競品（竹米 STENCIL＝Google Noto

1. **字型即根因**（§16.1）。沙箱量測「明圖界」筆寬：楷書中位數

   Sans TC（OFL 1.1，全專案最寬鬆授權）** 為鏤空字模推薦字型並設為
   預設。字型從官方 noto-cjk repo 單檔 OTF（5.8MB）抓、不必上傳
   fonts-v1 release（`render_fetch_fonts.sh` 加「絕對 URL」分支）。

2. **範本學技法非照搬**（§16.2）。方正大黑是商用字型（Founder 版權），
   打包進公開部署有訴訟風險——誠實標出、QODA 交還使用者判斷。使用者
   選 A：**演算模仿其連筋切法、跑在 OFL 黑體上**。

3. **軸向近牆橋接**（§16.3）。把 5dl 的 ±70° 斜向扇形改為**純軸向**
   逃逸＋**只穿近牆**（往內 2px 仍是墨才算方向）——修掉「穿越孔洞
   空腔鑿對側遠牆、對邊兩轉角併橋」的隱性 bug。實測 田/回/明 成
   方正式乾淨缺口、圖不再蜘蛛網；cutout 模式在黑體上本已乾淨故不動
   （最小範圍）。
