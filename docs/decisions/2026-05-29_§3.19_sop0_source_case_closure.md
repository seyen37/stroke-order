## 學到的規則 / pattern（適用未來）

### 規則 1：Sustained discipline 回報時序 ~10-11 天

5/14 day 1 §3.10 採用 → 5/24 §8.40 升等（10 天閉環）+ 5/14 day 2 SOP-0 提煉 → 5/25 §3.19 升 3rd practice（11 天閉環）。**source case provider 的回報可預測**、~10-11 天浮現。**Patience + sustained discipline > 急著做 governance**。

### 規則 2：Contingency memory 標準持續形成（第 3 條）

5/19 sandbox 失能 + 5/24 PS 三件套 + 5/29 divergence dance 三條同類 contingency。**模板穩定**：0 命中 + 高 impact + 短反應時間 + marginal cost ~30 min + option value 高 → 直接寫 memory。未來不用每次重思考標準。

### 規則 3：Catch 量隨工作密度波動、不是嚴格 exp growth

Catch 分布 1→7→17→14。5/29 低於 5/24 預測（17）— 因 user 工作密度分散。**catch 量是 trailing indicator、不該作為 audit cycle 決策依據**。5-7 天 cycle 才是 sustainable 維度。

### 規則 4：Audit day 從『新事件 driver』演化為『閉環 trace』

5/14-5/24 audit 都是「personal-playbook 升等了什麼、我們 cross-ref」 = 新事件 driver。5/29 是「我們 5/14 提的紀律被 close、記錄閉環」 = 閉環 trace。**source case provider 角色累積後出現的新模式**。

**未來 audit day 模式分類**：
- **新事件 driver**（新升等 / 新候選需 cross-ref）
- **閉環 trace**（我們的紀律被 close）
- **混合模式**（同 day 兩者皆有）

未來該在 §6.8 區分「新升等 row」vs「閉環 row」、避免混淆 source case origin。

### 規則 5：第 2 個閉環浮現後的 5 audit day 模式驗證

跨 5 audit day：1 個建立紀律 day（5/14 day 1）+ 3 個新事件 cross-ref day（5/14 day 2 / 5/19 / 5/24）+ 1 個閉環 trace day（5/29）。**比例 1 : 3 : 1**、預期未來持續類似分布。
