# ADR — 第二套正式主題「教師主題」（DESIGN.md §10）

- 日期：2026-11-16
- 版本：0.14.299 → **0.14.300**（四輪計畫 R1）
- 狀態：已實作（/guide、/myfont 套用；/teach 於 R2、/class 於 R3–R4）
- 相關：DESIGN.md §2（藍色主題鐵則）、**§10（本輪新立）**；
  `tests/test_design_md.py`

## 脈絡

11-16 使用者轉貼一則老師社群貼文：數位敘事力期刊以 Gemini Canvas 做的
「教育部筆順練習小工具」（筆順動畫、大螢幕練習、教育部字義、下載寫字格）。
用 Chrome 實看後的判斷：**功能與本站高度重疊，差在包裝**——它是暖米底、
白色大圓角卡片、朱紅主鈕、米字格當主角的「成品感」單頁；本站同樣功能
散在字帖／教學頁／手寫頁，觀感是灰色表單。老師社群對那份成品的反應就是
需求證據（Blueprint 原則 1）。

使用者決策（原話）：「A,+B，把這套設計語言寫進 DESIGN.md，配色要『暖色
主題』暖色主題只套在教師用的頁面（`/teach`、`/guide`、`/myfont`），寫進
DESIGN.md 成為正式的第二套主題，主工作頁維持藍色。」B 的描紅＝「自由
描寫」，B 的頁面＝「/class 課堂筆順」。

## 決策

### 1. 兩套主題並存，按頁面分界、不混用

| 方案 | 不選理由 |
|---|---|
| 全站改暖色 | 使用者明示主工作頁維持藍色；改動面過大 |
| 教師頁各自內嵌暖色 `<style>` | 三四頁各抄一份，必然漂移（5gb 雜色歸一的老病） |
| **共用 `static/teacher/theme.css`＋`--t-*` token（採用）** | — |

### 2. 與 §2 鐵則的衝突與解法

§2 鐵則「藍＝主要動作；紅＝破壞性專用」與暖色主題的朱紅主鈕直接衝突。
解法：**鐵則範圍收斂到主工作頁**，教師主題另立語意（§10.1）：朱紅＝主要
動作與筆順重點、墨綠＝練習與下載、暖黃＝提示與例句；**破壞性動作一律
ghost＋二次確認、永不填色**，避免與朱紅主鈕混淆。token 全部 `--t-` 前綴，
與 `--primary`/`--accent` 不同名（5gd 同名異義教訓）。

### 3. 守門測試（`tests/test_design_md.py` +5）

- §10 token 表 16 列進既有逐列同步鎖（文件與 CSS 不得漂移）。
- 教師頁必載 `teacher/theme.css?v=__V__`＋`body.t-page`，不得自訂
  `--primary`/`--accent`；頁面局部 `<style>` 不散寫色值。
- 朱紅值只准出現在 theme.css（不外流到主工作頁）；主工作頁不得載入
  教師主題。
- theme.css：無 `--accent`/danger 規則、ghost 透明底、`[hidden]` guard、
  `:root` 以外無散寫色值。

### 4. 對比（WCAG AA ≥4.5:1，實算）

白字/朱紅 5.17、白字/墨綠 6.29、輔助字/米底 5.50、輔助字/白 6.04、
提示字/黃底 6.59、朱紅字/米底 4.71。

## R3（v0.14.302）：/class 課堂筆順第一輪

新頁 `/class`（教師主題），一頁投影上課用：

- **輸入一個字或一個詞**（只留漢字、保留疊字、上限 10 字），多字時出現
  大字片逐字切換。範例：春天／園藝／好看／學（預設「春天」——教育部常用詞
  有收，第一眼就看得到詞語釋義）。
- **左**：米字格筆順播放器（與 /teach 共用 `player.mjs`）＋逐筆分解圖
  （`/api/steps` svg 內嵌，每列格數跟筆畫數、夾 4–10；另有分解圖 PDF）。
- **右**：字卡（注音／部首／筆畫）、**詞語釋義**（輸入是詞時，從第一個字的
  教育部常用詞整詞比對；查無照實說「本站收錄的常用詞（每字最多 12 條）沒有
  『…』」——build 腳本 `MAX_WORDS_PER_CHAR = 12` 是事實上限）、字義卡、
  造詞字片（點了換查該詞）。
- **下載 A4 寫字格**＝`/api/grid` PDF、米字格、每字一直行 10 格（範字＋描紅
  ＋空格）。字太少整頁只剩細長一條，所以把詞**重複到至少 6 行**
  （`gridChars`），一張就能發。載入完成前按鈕 `aria-disabled`。
- 純邏輯 `teacher/classcore.mjs`（`parseQuery`／`gridChars`／`gridUrl`／
  `stepsCols`／`stepsUrl`／`findWord`），node 測試直接驗。
- 計數桶 `/class → class_page`；route snapshot 加 `/class`；
  `TEACHER_PAGES` 加 class.html。

不在本輪（R4）：自由描寫、全螢幕投影模式、/guide 入口。
