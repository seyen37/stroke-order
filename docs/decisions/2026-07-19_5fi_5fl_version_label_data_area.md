# 5fi～5fl 主頁版本標籤＋筆順練習資料區三輪收斂：QODA 重放

- **日期**：2026-07-19（第七階段）
- **版本**：0.14.250 → 0.14.254（6803c09 → 47011dc → 77319a5 → af02556）
- **對應原則**：§61–§63（§57 追加 case）

## 背景

四輪皆使用者明確規格：主頁要看得到版本；筆順練習的資料功能
（統計/提交/匯入/清空/匯出）連三輪指定新位置，最終收斂到左欄
一條龍。QODA 重心在測試治理與驗收經濟，不在版面本身。

## 決策一：主頁版本標籤走注入（5fi，§57 追加 case）

選項：A 手刻版本字串（上輪剛因手刻 v0.13.0 卡十幾版）／★B 空殼
`span#app-version`＋JS 讀第一個帶 `?v=` 資產的版本參數填入。
定案 B——單一事實源＝資產版本參數（`_versioned_text` 注入），
升版零維護。附帶紅燈一次：`test_version_injection` 禁字面
`__V__`，我的 JS 註解與 guard 字串踩線——gate 抓的正是「不是
bug 但會誤導」的殘留，改寫措辭與正則（`\d[\w.]*`）後過。

## 決策二：資料區三輪收斂與測試治理（5fj→5fl，§61）

三輪遷移：5fj（統計/提交→左欄；匯入/清空→畫布右下）→
5fk（匯入/清空→左欄＋二次確認）→ 5fl（匯出三鈕→左欄；抽屜
移除）。終局＝左欄 `#hw-side-data` 統計→提交→匯入→清空→
匯出×3。工程準則：

- **佈局斷言集中「終局測試」**：`test_5fj_data_area_relayout` →
  `test_5fj_5fk_…` → `test_5fj_5fl_…` 隨版面改名續版；舊輪測試
  的版位斷言移交＋留註記（5fl 被 test_5ez 的 `hw-data-row-inline`
  咬紅一次——版面斷言散在歷代測試＝每輪搬家都有地雷）。
- **per-element 綁定讓搬家零 JS**：所有行為綁 id/data-action
  （querySelector 逐元素），三輪 DOM 大搬家 JS 行為程式碼零改動。
- **dead UI 不留**：抽屜搬空即整段移除（HTML+CSS）；入口鈕
  「≡ 我的資料」不刪、改捲動到左欄資料區＋刷新統計——affordance
  保留、語意跟著內容走。

## 決策三：清空整庫二次確認（5fk，§62）

不可復原的整庫刪除雙 confirm：第一關給退路（建議先匯出備份）、
第二關「最後確認」明示範圍與不可復原；兩關都在 `clearAllTraces()`
之前。測試兩層：靜態鎖「處理器內恰 2 個 confirm( 且都在動手前」；
E2E dialog handler「第一關接受＋第二關取消」驗資料完好——驗的是
**攔截力**，不是 confirm 字樣存在。

## 決策四：「恢復逐字手寫的按鈕」——先重現、帶證據問（§63）

需求一句話有三種解讀（常駐化／深連結返回鈕消失 bug／主頁視窗
按鈕）。先本機重現該鈕全部出現路徑：深連結（from= 參數）實測
按鈕正常出現、程式歷史確認它從未常駐。把驗證結果寫進選項再問
（AskUserQuestion），使用者選「維持現狀」——零改動結案。若不先
驗證就動手，三個解讀猜錯兩個。

## 決策五：驗收經濟——使用者截圖折抵自動驗收（§63 姊妹律）

0.14.253 push 後 18 分鐘的自動驗收 trigger 已排；使用者隨後貼的
production 截圖含版號＋完整版面＝比 curl 更強的驗收證據——撤
trigger 不重複驗（免費層資源與通知噪音都省）。輕量 curl 驗收
模板保留給無截圖的輪次。
