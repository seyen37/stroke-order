# 決策紀錄 2026-07-13（第二弧）：5db→5df-1c 雷切線與禪繞地基

對應 PRINCIPLES §12。0.14.167 → 0.14.174，tests 1659 → 1676。

## D1. 快取版本化的完整清單（5db，§11.4 補遺）

「版本進快取鍵」要涵蓋**所有會快取該資源的層**：伺服器落地檔
（檔名帶版本）、部署燒入檔（同）、**瀏覽器 HTTP 快取（URL 即
鍵，query 就是它的版本欄位）**。5da 清了前兩層漏了第三層——
max-age 7 天的舊回應讓升級後仍懸掛。驗證法：裸 URL vs no-store
vs 帶 query 三發 fetch 比 bytes，一翻兩瞪眼。

## D2. 鏤空字雙子模式＝幾何對偶（5dc）

使用者補充的「噴漆字 vs 鏤空字」細分讓設計收斂成對偶：stencil
鑿白橋（把孔洞孤島接回大板）、cutout 補黑橋（把斷件連成一件）
——同一條光柵管線、兩個方向相反的橋接演算法。邊框＝「框也是
一個黑元件」，連筋演算法自動把字掛上框，零特例碼。

## D3. run 填色 flood 取代單像素 frontier（5dc）

大畫布（千 px 級）上 frontier flood 要數千迭代；「列/行 run
整段填色交替至不動點」數個 pass 收斂、正確性等價 4-連通。
凡光柵拓撲（外部判定/連通元件）都適用。

## D4. 造型感知＝在消費點取幾何，不信 bbox（5dd/5de）

bbox 假設只對「滿弦」造型成立。正解：在文字列實際高度取造型
水平弦（字框上中下三線交集＝凸形精確/凹形保守），字級、間距、
列心全部跟弦走；auto 字級＝同一收斂器把起點改大（bbox 對角），
「只會縮」自動變成「能縮能放」。鋪排公式做成舊公式的弦版，
滿弦時退化全等＝金標零回歸。

## D5. 朝向系統＝資料變換，不是圖樣變體（5df-1）

四向朝向做成單一純函式 orientSpecs（spec 列繞區心旋轉），八個
圖樣自動獲得四向；90/270 用轉置尺寸建格再旋轉，非正方形不溢框。
「朝向存區段、渲染時疊加 tile 旋轉角」——旋轉相容在資料模型層
解決，UI 層（5df-3）只改一個欄位。

## D6. 界內測試先行，三殺證明（5df-1b/1c）

六個新圖樣三個有越界蟲（paradox 外接半徑、hollibaugh 帶外伸、
外加舊斷言釘常數），全被同一條「所有 spec 座標落區域內」測試
在上機前攔下。鐵則：新圖樣網格迴圈邊界要含元素最大外伸半徑、
先過界內測試再入 registry；grep 舊斷言的範圍必須含 tests/*.mjs。
