## 脈絡

Blueprint v1.0 把 Phase 0 定為「不寫新功能的驗證期」：最大隱憂是驗證
真空（2,241 測試證明做的東西對、零回饋證明做的是對的東西）。使用者
sign-off「自動執行」三項，設計決策授權自行裁定——本 ADR 記錄裁定與理由。

## 決策

### D3 測試分層：模組層標記、先量再標

- **量測**：--durations 實測，慢源集中五檔（test_page_pdf ~45s、sutra、
  render_cache、chiron_round_vf、popup——全是光柵化/PDF）。
- **裁定**：模組層 `pytestmark = pytest.mark.slow`（不逐測試標——慢的
  是整檔的性質）；pyproject 註冊 marker；**收工檢查照跑全套不變**，
  分層只給開發迭代用。
- **結果**：快車道 `-m "not slow"` 77s vs 全套 167s（省 54%）。

### D2 需求儀器化：只數次數、不記人；暫時性磁碟誠實補償

- **隱私裁定（最重要）**：counter 只有功能名與字元——無 IP/UA/cookie/
  時間序列。**鎖成測試**（快照恆為四鍵）。理由：這是路線圖溫度計，
  不是分析平台；教育場景的信任成本 >> 精細數據的價值。
- **掛點**：模式計數走純 ASGI middleware（§50 教訓）＋16 功能面前綴表
  （有界集合）；缺字計數掛 char_pipeline 404（＝R2 翻案感測器），
  500 key 上限＋overflow 總數（誠實溢位）。
- **持久化裁定**：JSON 檔（env 可調目錄）＋節流 flush＋metrics-flush
  log 行。Render free tier 磁碟是暫時的——不假裝可靠：快照帶 since
  視窗、log 留歷史、gate 判定明定用相對訊號。**不上 DB**：G3 前的
  過早優化（Blueprint §5.3）。
- **失敗語意**：磁碟寫不進只失去持久化，計數活在記憶體、主流程零影響
  （鎖成測試）。

### W0 老師說明頁：教案語言、自包含、誠實措辭

- **裁定**：獨立靜態頁 `/guide`（照 /teach 慣例），不是 README 的連結
  ——觸達對象是老師，語言是「三步印出來」不是「API 參數」。
- 自包含無外連（教室離線可印）；措辭守門鎖成測試：分級只講字頻名次
  （W4）、查無此字如實說（§87）、ND 出處照實（§88）。
- Playwright 截圖目視通過（§96：有版面的產物收工前用眼睛看）。
