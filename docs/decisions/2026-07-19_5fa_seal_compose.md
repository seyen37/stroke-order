# 5fa 篆體缺字部件合成：QODA 重放（誠實推測，非原典）

- **日期**：2026-07-19（第四階段）
- **版本**：0.14.242 → 0.14.243（131be86）；5fb 補強 0.14.244
- **對應原則**：§53
- **狀態**：線上驗收 PASS——週期表 118/118 滿格、缺字 60→0、62 字合成

## 背景

崇羲篆體收錄《說文》＋教育部常用字；「罣」「耨」與元素週期表現代
造字（鋰鈧鈦釩…）皆缺，依 5at 設計退回楷書。使用者需求：拆部件
（罣＝网+圭、耨＝耒+辱、元素字＝金/石/气＋聲旁）重組近似篆形。

## 決策一：合成範圍（QODA）

★A 部件合成引擎（零新依賴）／B cjkvi-ids 全覆蓋（GPL 治理＋1MB，
留二期）／C 只做元素 118 字。定案 A：

- 拆解來源①元素特化表 102 字（現代字不在會意 DB；只收高把握項）
  ②朱邦復五千字會意 DB 3,719 字（**本庫既有**，且給的是 网 而非
  楷書縮略的 罒——正合小篆組字用完整部件形的傳統）。
- DB 是語意序（字首/字尾）無空間方位——以保守的部首方位表推測
  （金木水…→⿰、网艹雨…→⿱、气→⿹）；**推不出方位誠實放棄**
  （維持退楷書）＝覆蓋率提升零品質風險的「誠實放棄曲線」。
- 部件取件走 get_character 本尊：簡繁/異體變體鏈與巢狀合成免費
  復用（實證：鉨 的聲旁 尔 走 尔→爾 變體鏈成功）；_composing
  集合防循環。

## 決策二：誠實標示（QODA）

★標示：合成字 validation_notes 帶 "seal-synth:⿰金里" → cellmap
data-seal-synth（隨分批合併同步）＋預覽狀態列「含 N 字部件合成
篆字（推測非原典）」。字形本身不改色（列印乾淨）。
關鍵相容細節：**data_source 必須維持 "chongxi_seal"**——骨架/描邊
轉換管線（apply_seal_outline_mode）依它分流，合成字要走同一條；
「是不是合成」另走 notes，不汙染分流語意。

## 幾何
