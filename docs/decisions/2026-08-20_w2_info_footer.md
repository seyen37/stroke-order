# ADR — W2 字帖頁尾生字資訊區

- 日期：2026-08-20
- 版本：0.14.289 → **0.14.290**
- 狀態：已實作
- 相關：§88（CC BY-ND 節錄規則）、§5bv（不用 `<text>`）、§87（不裝懂）、
  W1（`fit_svg_to_paper`／PDF 出口）、T2（教育部辭典 bundle）

## 脈絡

字帖評估建議書盤出三個缺口，W1／W3 做掉了「印不出來」與「紙本連不回線
上」。剩下的是：**練完一整張字，學生還是不知道這個字是什麼意思**。

手上已有的：教育部《國語辭典簡編本》離線 bundle（6,028 字，隨 repo 部署、
零外部服務），含注音／部首／筆畫／釋義／常用詞。缺的只是排到紙上。

已知條件：

- 釋義授權為 **CC BY-ND**（可商用、**不得改作**）。
- 整條 `definition` 中位 36 字、90% 到 109 字——字帖版面放不下。
- 字帖整張會等比縮放貼進 A4（W1）。
- Render 的 `apt.txt` 只有 cairo 系列，**沒有任何 CJK 字型**。

## 決策

### D1：釋義取「第一個完整義項」，要嘛整條、要嘛不放 ★

| 方案 | trade-off |
|---|---|
| 截斷到 N 字加刪節號 | 版面永遠塞得下，但**是改作**——ND 不允許 |
| 自行摘要 | 更好讀，但**是改作**，且會產生我們掛保證不了的內容 |
| ★ 取第一個完整義項；超過長度預算整段換告示語 | 節錄整個單元＝選取，合規；代價是 9.7% 的字看不到釋義 |

**取一個完整義項是選取，切斷一個義項不是**——線畫在單元邊界，不在字數。
放不下時整段換成「釋義較長，見完整條目」，**絕不出現刪節號**：刪節號等於
宣告「這裡本來還有字」，那正是改作的痕跡。

義項切分用 `\n+` 而非 `\n\n`（實測 2,935 條是單 `\n` 分隔，只切 `\n\n`
會讓近半數的字取到整條釋義），並**保留原本的「1.」「2.」編號**——拿掉序
號是對內容動手。

### D2：長度預算 40 字，與版面寬度脫鉤 ★

`INFO_MAX_CHARS = 40` 覆蓋 90.3% 的第一義項（實測：中位 18、75% 25、
85.5% ≤32、90.3% ≤40、max 227）。

這是**版面預算**不是授權判準：再長會把頁尾撐成好幾倍高、喧賓奪主。版面
**寬度**放不下則用**換行**處理——換行不減字，與授權無關。第一版把兩者
混在一個 `capacity` 參數裡，結果連 `meta` 欄位都被截掉。

### D3：字級相對版面寬度，不綁格高 ★

`text_em = min(EM_SIZE*0.18, 版面寬/40)`。

只綁格高的話，兩個生字的窄字帖放大到 A4 後註記會變半個標題大（實測一列
只排得下 11 個字）。取 `min` 保留上限，寬字帖不會讓字級無限放大。

### D4：註記字形走 noto_hei，並在渲染時量墨跡 ★

| 方案 | trade-off |
|---|---|
| `<text>` | 最省事，但 §5bv 已踩過：cairosvg 吃**伺服器**字型堆疊，Render 無 CJK → 空框 |
| 字帖字源（g0v/kanjivg…） | 零新相依，但**只有漢字**——數字與全形分隔符號全缺，釋義的「1.」編號正好踩到 |
| ★ noto_hei（思源黑體）字形路徑 | 涵蓋完整；Render 已有 `STROKE_ORDER_HEI_FONT_FILE`，不新增部署相依 |

代價：noto_hei 字形是**基線相對**的，不填滿 em 框（實測墨跡 y∈[573,
2728]／EM 2048，下緣超出框 0.33 em）。所以畫布高度用**渲染時量出的實際
墨跡上下緣**（`_ink_band`）算，而不是假設「框高＝字級」——第一版就是後者，
PNG 上最後一列被削掉半個字。這樣對任何字形來源都成立。

字型檔缺席時整個註記區留白，**不以任何符號代替**（§87 不裝懂）。

### D5：opt-in，預設關 ★

頁尾會**加高整張 SVG**，開了就改變既有字帖的輸出尺寸。預設關，且關著時：

- 輸出與 W2 之前**逐位元組相同**（`total_h_em` 特別保持 `int`，否則
  viewBox 會從 `6144` 變成 `6144.0`）。
- **連字典都不查**——端點層 `if info_footer:` 才呼叫 `build_info_rows`。
- `gcode`／`json` 完全不受影響。

## 分層

| 層 | 職責 |
|---|---|
| `sources/moe_dict.py` | `split_senses()`／`first_sense()`——只切不改 |
| `web/char_pipeline.py` | `build_info_rows()`——查字典、備字形（伺服器層） |
| `exporters/grid.py` | `compose_info_line()`／`_info_footer_svg()`——只排版 |
| `web/routes/modes_text.py` | `info_footer` 參數；關著時不呼叫上面任何一個 |

「放不下怎麼辦」只寫在 `compose_info_line()` **一處**——ND 的線只有一個
決策點，別處要違反得先改它。

## 後果

- 老師勾一個選項就能印出附釋義的字帖，學生不必翻字典。
- 9.7% 的字（第一義項 >40 字）只看得到「見完整條目」——誠實優於猜。
- 頁尾字形固定為黑體，與字帖本身的風格（楷書／圓體／篆隸）不同——這是
  刻意的：註記是**讀**的，字帖是**寫**的。
