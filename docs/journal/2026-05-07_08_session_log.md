## 5/8 上午：6z-2.1 frame 共同旋轉（commit `e05f705`, bump 0.14.126）

### User 反饋

> 「視覺驗證，看到字的旋轉，但是視覺上，應該是外框連同字，一起旋轉，是『紙磚』整個連動的視覺效果」

### Bug root cause

```
6z-2 原 pipeline:
  drawTileBackground (axis-aligned 邊框 + 4 dot)  ← 不轉
  + rotateContours (只轉 outline polylines)      ← 轉
  + drawOutline                                  ← 旋轉後的字
```

Frame + outline 在不同 transform space → 字轉、磚不轉、視覺違反 metaphor。

### 修法

`withTileRotation(fn)` ctx transform 包整個 redrawAll：

```js
ctx.save();
ctx.translate(cx, cy);
ctx.rotate(deg2rad);
ctx.translate(-cx, -cy);
fn();  // drawTileFrame + drawOutline 全在同一 transform
ctx.restore();
```

順便加 `_cachedContours` 解 6z-2 R1 (slider drag fetch race)：rotation/tile change 不 re-fetch、char/source change 才重 fetch。

**結果**：slider drag 60 fps → 0 server hit + 0 race。

**新加 PRINCIPLES**：[§6.11 Canvas 整體變換用 ctx transform](../PRINCIPLES.md#611-canvas-整體變換用-ctx-transform)。

## 5/8 中午：6z-2.2 pan buttons（commit `0c34a83`, bump 0.14.127）

### User 反饋

> 「在紙磚旋轉的情況下，邊角超出可視區域，請在紙磚外框設計快速紐 ... 按一下即紙磚移動，觀看按鈕這一側邊，原先超出可視區的區域，再按一下即恢復原紙磚中心點」

### 數學

對 600×600 tile 旋轉 45°：
- bbox extension = ts·(|cos θ| + |sin θ|) = 849px
- 對角溢出 = (849 - 600) / 2 = **124 px per side**

### 實作

`_panState ∈ {center, top, bottom, left, right}` per-session（鏡像 `_rotationDegrees` 政策、不 persist）：

```js
function computePanOffset() {
  const v = rotationOverflow();  // (ts·(|cos|+|sin|) − ts) / 2
  switch (_panState) {
    case "top":    return [0,  v];   // 紙磚 DOWN → 露出 top 超界
    case "bottom": return [0, -v];
    case "left":   return [ v, 0];
    case "right":  return [-v, 0];
  }
}
```

`withTileRotation` 加 `ctx.translate(panX, panY)` 在 rotation 之前：`M = T(pan) · T(c) · R(θ) · T(-c)`。

CSS grid 3×3 包 canvas，4 button 在中間軸：
```
       ↑ 上
  ←左 [canvas] →右
       ↓ 下
```

Active button 紅底白字（`refreshPanButtonHighlight`）。

## 5/8 下午：6z-2.3 箭頭方向修正（commit `5eca676`, bump 0.14.128）

### User screenshot 反饋

```
       ↑ 上 (正確)
[↑左] [canvas] [↓右]
       ↓ 下 (正確)
```

左右 button 顯示 ↑ 和 ↓，跟「left / right」 直覺反。

### Bug root cause

CSS `writing-mode: vertical-lr` 讓 button 整段文字旋轉 90° CW：
- `← 左` (左箭頭 + CJK) → `← ` 旋成 `↑`、`左` CJK 保持垂直 → 顯示「↑ 左」
- 同理 `→ 右` → 顯示「↓ 右」

### 修法（6 行 CSS）

- 移除 `writing-mode: vertical-lr`
- 加 `white-space: nowrap`
- 右 button 改成「右 →」 與左 button「← 左」 鏡像對稱、兩側箭頭都指向「露出方向」
