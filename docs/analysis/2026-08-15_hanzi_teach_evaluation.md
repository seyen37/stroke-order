# 評估建議書：「漢字部件與部首互動教學」（Gemini Canvas 第127彈）× stroke_order

日期：2026-08-15｜參考對象：同好以 Gemini Canvas 製作的教學工具（輸入單字→
部件分析＋字義＋繪本插圖＋造詞造句＋TTS 語音＋下載自包含 HTML 上課用）
本專案：stroke_order（v0.14.282，中文字元 → 向量筆跡／教學輸出）

---

## 0. 摘要（一段話版）

這個工具的六個組件裡，**四個你已經有現成地基**（部件拆解、部首、注音／筆順、
自包含 HTML 下載），一個可以用**瀏覽器內建 TTS** 零成本補上（它的「電腦音
後備」在你這反而是主路徑），剩下的 LLM 缺口（字義／造詞造句）可以用**教育部
四部辭典的開放資料**（CC BY-ND 3.0 臺灣，可商用）正面解掉——只有「繪本插圖」
無解也不必解（留圖片槽給老師）。也就是說：**別人要靠 Gemini 即時生成的東西，
你可以用靜態開放資料＋既有 API 做成離線可用、資料可查證的版本**——這正好把
它自己承認的弱點（「資料都是 AI 生成，要使用之前一定要確認」）變成你的差異化：
教育部辭典來源＝老師不必再逐條查核。

---

## 1. 它的做法解讀（從描述反推）

輸入一字 → LLM 即時生成：部件拆解說明、字義、繪本風插圖（圖片生成）、常用
造詞＋情境造句；TTS 走雲端語音（失敗降級瀏覽器 speechSynthesis）；最後打包
自包含 HTML（內嵌已生成的語音）供離線上課。強項：內容生成零資料庫、話術
自然、插圖吸睛。弱項（發文者自己點名）：**AI 生成需逐條查核**；且依賴
Gemini 服務（斷網/額度/連結失效都是風險——發文者自己都被斷網兩天）。

## 2. 六組件對照表

| 組件 | 它的做法 | stroke_order 現況 | 判讀 |
|---|---|---|---|
| 部件拆解＋說明 | LLM 生成 | `/api/decompose/{char}`（IDS 結構）＋`/api/components/{char}`＋部件家族——**已有** | 現成，且可畫部件分色圖 |
| 部首 | LLM | 康熙部首資料（radicals.py／描紅頁已用）——**已有** | 現成 |
| 注音／發音標注 | — | 注音資料線（5cr~5da 弧）——**已有** | 加值：它沒有的 |
| 筆順 | — | 筆順動畫／描紅（hanzi_writer、骨架資料）——**已有** | 加值：它沒有的 |
| 字義＋造詞造句 | LLM 生成（需查核） | 無 | **缺口**→教育部辭典開放資料可解 |
| 繪本插圖 | 圖片生成 | 無 | 不解：留圖片槽（老師自備） |
| TTS 語音 | 雲端 TTS＋瀏覽器後備 | 無 | 瀏覽器 speechSynthesis 當主路徑（零服務、離線可用） |
| 下載自包含 HTML | 內嵌生成語音 | popup/卡片模式已有單檔下載慣例 | 現成慣例；語音改執行期合成（見 §4 取捨） |

## 3. 關鍵解方：教育部辭典開放資料（字義／造詞缺口）

[教育部國語辭典公眾授權網](https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/index.html)
提供四部辭典完整資料下載：**重編國語辭典修訂本／國語辭典簡編本／國語小字典
／成語典**，授權皆為「創用CC-姓名標示-禁止改作 3.0 臺灣」——可重製、散布、
傳輸（**含商業利用**），條件是姓名標示＋**不得修改內容**。對教學頁的意義：

- **國語小字典**＝專為國小生編——字義淺白，正對「上課用」場景。
- **簡編本**＝常用詞書證＋例句——「常用造詞＋造句」直接有官方版本。
- ND（禁止改作）＝**逐字原文呈現＋標示出處**即可，教學頁本來就該原文呈現
  ——授權模式與現有崇羲篆體（CC BY-ND 4.0）同類，`licenses/` 治理直接套用。
- 差異化本質：**AI 生成要查核 vs 教育部辭典免查核**。這一點對老師是決定性的。

工程面：資料檔一次下載、離線建索引（比照 g0v bundle 的 JSONL 懶載慣例，
避免重蹈 §36 全量解析 OOM）；體積挑選用（小字典＋簡編本子集）不必全上。

## 4. QODA 選項

### T1★★★ 「識字教學頁」模式 MVP（推薦首發，零新資料源）

**方案**：新增 `/teach` 獨立頁（自包含 inline JS，照 popup 慣例）：輸入一字→
現有 API 帶出 部件拆解（分色部件圖）＋部首＋注音＋筆順動畫描紅格；
**TTS 用瀏覽器 `speechSynthesis`（zh-TW）**，字／詞點了就唸；字義與造詞
先做「可編輯欄位」讓老師上課前自填；「下載教學單檔 HTML」把當前內容
（含老師填的字義）打包成離線單檔。
**價值**：一輪就有可上課的東西；全部現有資產重組，無授權議題、無新相依。
**工作量**：中。**取捨**：下載檔的語音是**執行期合成**（開檔時用該機器的
語音引擎唸，非內嵌音檔）——離線可用但音色隨機器；不像它內嵌固定音檔。

### T2★★ 接教育部辭典開放資料（字義／造詞自動帶入）

**方案**：新增 `sources/moe_dict.py`：小字典＋簡編本資料檔（JSONL 懶載）→
`/api/dict/{char}` 回字義／常用詞／例句；T1 的可編輯欄位改「自動帶入＋
可改」。`licenses/` 加 CC BY-ND 3.0 TW 條目＋頁面出處標示。
**價值**：補齊最後一塊 LLM 缺口且**免查核**（勝過原工具的核心點）。
**工作量**：中（資料清洗＋索引＋授權治理）。**建議 T1 之後**。

### T3★ 插圖槽（不生成、不強求）

教學頁留「插圖」上傳槽（老師自備圖或留白），沿用卡片模式的圖片匯入
sanitize 慣例。**工作量**：小（隨 T1/T2 附帶）。

### 明確不建議：接 LLM／圖片生成

即時生成字義或插圖＝引入外部 AI 相依＋查核負擔＋金鑰管理，正是原工具被
自己點名的弱點；與 stroke_order「靜態開放資料、離線可用、可查證」的定位
相反。**不做**。

## 6. 授權與合規

教育部辭典＝CC BY-ND 3.0 TW（可商用、不得改作、需標示）——教學頁原文呈現
＋出處標示即合規；比照 `licenses/` 慣例加條目。瀏覽器 TTS 無授權議題
（OS 內建）。原工具只是概念參考、無程式碼可抄的問題。

## 7. 結論與下一步

它證明了「單字→部件教學單頁」是老師真實想要的東西（同學提案、兩個月做
成）；你手上的資料資產做同型工具**不需要 LLM**，且能在「資料可信」上直接
勝出。建議 T1 先行。**等你 sign-off**：選 T1 就出細部規格（頁面版位、API
組裝、下載打包、測試不變式）再動工。
