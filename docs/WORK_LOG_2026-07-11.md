## 二、本日學到的規則

### CJK 一律描邊、`<text>` 只放 ASCII（再度驗證）
節氣日期提示原寫「約 2/4」，「約」在無 CJK 字型主機（cairosvg → PDF）變
豆腐字。與 5bv mark_renderer="polyline" 同源教訓：凡會經過 server-side
rasterise 的 CJK，一律走 char_loader 描邊；`<text>` 保留給數字與拉丁。

### 慢渲染 API 測試 → stub loader，正確性由 exporter 層扛
全頁 118 字真實渲染 40-60s，不入測試。API 測試 monkeypatch `_load` 驗
路由與組版；glyph 正確性由 exporter 單元測試＋視覺驗證覆蓋。乘法表／節氣
只有 11／25 個相異字，exporter 內建 memo loader，真實渲染 0-4s。

### 協作沙箱掛載同步會「前半新後半舊」
Windows 側 Edit 後沙箱 mtime/size 不更新 → Python 沿用舊 .pyc、檔案讀取
被舊長度截斷。解法：`git archive HEAD` 建乾淨副本＋程式化重套修改再驗證；
Windows 側檔案為權威版本。已記入協作 memory。

## 二之三、第三批（同日續）：5bp 打包經文 — 修線上文本全缺陷

**發現**：開工查線上 API 發現 Render 上**全部 54 部 builtin 都是
ready: false**（含心經）——`~/.stroke-order/sutras/` 在 Render 是
ephemeral，文本從未有部署機制，線上抄經模式一直只有介面沒有內容。

**解法（5bp）**：不做啟動 seed，改在 `_resolve_builtin_path` 加第三層
fallback：打包目錄 `src/stroke_order/data/sutras/builtin/`（53 部，
NFC/LF 正規化）。搜尋順序＝使用者檔 → legacy flat → 打包文本；
`STROKE_ORDER_PACKAGED_SUTRAS=0` 可關（temp_sutra_dir fixture 用它
保住「未載入」行為的可測性）。git push 即部署、本機新安裝開箱即用、
QUICK_START 的「丟檔案」步驟從此變選配。

**版權**：`macarthur_prayer` 中譯著作權未確認，保守不打包（metadata
保留、本機自放可用）；其餘公版古籍／和合本（1919）／教會儀文／
事實彙編，註記見 `data/sutras/SOURCES.md`。新增 CI guard 測試：
未來新 preset 忘附打包文本會直接紅。
